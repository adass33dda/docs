## Make Sanity yours

Sanity ships with a clean default look, but every server has its own vibe. Swap out the avatar, drop in a banner, and write a bio that actually sounds like your community. It only takes a minute.

<Warning>
  Keep it clean. Every upload is logged and reviewed. Anything inappropriate gets the bot yanked from your server, no warnings, no appeals.
</Warning>

<Info>
  These commands are locked to the **server owner** only. Staff and admins can't run them.
</Info>

## Avatar

Give Sanity a profile picture that fits your server's aesthetic.

<CodeGroup>

```txt Command
,customize avatar (image url)
```

```txt Example
,customize avatar https://sanity.ws/avatar.png
```

</CodeGroup>

## Banner

The banner shows up on Sanity's Discord profile card. Use it for branding, art, or just a nice color splash.

<CodeGroup>

```txt Command
,customize banner (image url)
```

```txt Example
,customize banner https://sanity.ws/banner.png
```

</CodeGroup>

## Bio

Write a short blurb that appears under Sanity's name in your server. Great spot for a slogan, a link, or a joke your members will get.

<CodeGroup>

```txt Command
,customize bio (text)
```

```txt Example
,customize bio keeping the vibes immaculate since 2024
```

</CodeGroup>

<Info>
  Sanity automatically appends a link back to [**sanity.ws**](https://sanity.ws/) or **discord.gg/sanity** if you don't include one yourself. This keeps the bot discoverable to new users.
</Info>

## Resetting

Want to start fresh? Use `,customize reset` to wipe everything at once, or reset a single field on its own.

<CodeGroup>

```txt Reset all
,customize reset
```

```txt Reset avatar
,customize avatar reset
```

```txt Reset banner
,customize banner reset
```

```txt Reset bio
,customize bio reset
```

</CodeGroup>
