## Invite the bot

Head to [sanity.ws](https://sanity.ws) and click **Invite** to add Sanity to your server. Keep the default permissions so every module works out of the box.

## Set the command prefix

Sanity uses `,` as the default prefix. You can swap it for anything you like.

```txt
,prefix set !
```
