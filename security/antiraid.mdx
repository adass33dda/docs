## Configuring the antiraid system

### Preventing mass joins

This module will trigger when the number of accounts joining the server exceeds the threshold within a short time frame.

<Warning>
  Whenever the threshold is reached, the server will be placed in a raid state. This will temporarily disable intensive events which Sanity dispatches, such as **welcome** and **goodbye** messages.
</Warning>

<CodeGroup>

```txt Syntax
,antiraid massjoin (on | off) --threshold <number> --do <kick | ban> --lock <true | false> --punish <true | false>
```

```txt Example
,antiraid massjoin on --threshold 5 --do ban --lock true --punish true
```

</CodeGroup>

<AccordionGroup>
  <Accordion title="Threshold">
    Number of joins required inside the raid window before Sanity flags the burst as a raid. Set with `--threshold <number>`.
  </Accordion>

  <Accordion title="Punishment">
    Action applied to members caught in the raid. Set with `--do kick` or `--do ban`.
  </Accordion>

  <Accordion title="Lock channels">
    When `--lock true`, Sanity locks text channels the moment a raid is detected so raiders cannot spam while staff respond.
  </Accordion>

  <Accordion title="Punish new accounts">
    When `--punish true`, Sanity applies the configured punishment to recently joined members who match the raid window.
  </Accordion>
</AccordionGroup>

### Requiring an avatar

This module will trigger when an account joins the server without an avatar.

<CodeGroup>

```txt Syntax
,antiraid avatar (on | off) --do <kick | ban>
```

```txt Example
,antiraid avatar on --do kick
```

</CodeGroup>

<AccordionGroup>
  <Accordion title="Punishment">
    Action applied to accounts that join without a profile picture. Set with `--do kick` or `--do ban`.
  </Accordion>
</AccordionGroup>

<Frame>
  ![Enabling the avatar antiraid module in Discord](/images/antiraid/avatar.png)
</Frame>

### Setting a minimum account age

This module will trigger when an account joins the server that is younger than the specified age.

<Info>
  The `threshold` flag is the number of days for an account to be considered old enough.
</Info>

<CodeGroup>

```txt Syntax
,antiraid newaccounts (on | off) --threshold <days> --do <kick | ban>
```

```txt Example
,antiraid newaccounts on --threshold 7 --do ban
```

</CodeGroup>

<AccordionGroup>
  <Accordion title="Threshold">
    Minimum number of days an account must exist before it is allowed to join. Set with `--threshold <days>`.
  </Accordion>

  <Accordion title="Punishment">
    Action applied to accounts younger than the threshold. Set with `--do kick` or `--do ban`.
  </Accordion>
</AccordionGroup>

<Frame>

### Exempting accounts from the antiraid

You can exempt accounts from the antiraid with the `antiraid whitelist` command.

<Info>
  You can use the `antiraid whitelist view` command to view all whitelisted accounts.
</Info>

<CodeGroup>

```txt Syntax
,antiraid whitelist (member)
```

```txt Example
,antiraid whitelist @Inboards
```

</CodeGroup>

## What to do after a raid

<Steps>
  <Step title="Cleaning up">
    Review the security log for the raid entry, then use `,antiraid state off` once you have confirmed the burst has ended. Sanity keeps recent raid joins in the log so you can audit anyone that slipped through.
  </Step>
  <Step title="Tightening thresholds">
    If the raid got past your current settings, lower `--threshold` on `massjoin`, raise the required account age, or switch punishments from `kick` to `ban` until the pattern stops.
  </Step>
  <Step title="Locking down verification">
    Pair antiraid with Discord's built-in verification level and a members-only role gate so future raids hit a wall before they even reach your channels.
  </Step>
</Steps>
