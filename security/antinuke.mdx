## Overview

The antinuke system watches high-impact events (channel wipes, mass bans, role deletions, webhook creation, and more) and stops the actor before real damage lands. Each module can be toggled independently with its own punishment.

<Frame>
  ![Antinuke overview in Discord](/images/antinuke/overview.png)
</Frame>

## Enabling antinuke

Antinuke must be turned on at the server level before any module will act.

<CodeGroup>

```txt Syntax
,antinuke (on | off)
```

```txt Example
,antinuke on
```

</CodeGroup>

## Modules

Every module follows the same shape: turn it on, set a threshold if applicable, and pick a punishment.

<CodeGroup>

```txt Syntax
,antinuke <module> (on | off) --do <kick | ban | strip>
```

```txt Example
,antinuke channel on --do ban
```

</CodeGroup>

## Admins

Antinuke admins are trusted users allowed to configure and manage antinuke itself. Only the server owner can add or remove admins.

<CodeGroup>

```txt Syntax
,antinuke admin (member)
,antinuke admins
```

```txt Example
,antinuke admin @Inboards
```

</CodeGroup>

## Whitelist

Whitelisted users and bots are exempt from antinuke punishments. Use this for trusted staff, bots, and integrations.

<CodeGroup>

```txt Syntax
,antinuke whitelist (member | bot)
```

```txt Example
,antinuke whitelist @Inboards
```

</CodeGroup>
